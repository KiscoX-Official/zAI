# zAI - Una app para poner AI KEY ligera que podes usar hasta en una papa con cables (O, segun, una PC lenta, pero tampoco te pases y te pongas a correrlo en WindowsXP) (Solo español)

 zAI es una aplicacion donde puedes usar una IA sin pesar tanto ni usar tanto el navegador, como es esto posible? la explicacion es simple, usando NiceGUI, Python, pathlib y otros, pude hacer esta aplicacion

 **Como funciona?** Es muy simple de usar, primero, te tienes que ir a Google AI Studio, osea (https://aistudio.google.com/), luego, irte a Crear clave de API, la creas, la copias, y la insertas en la caja donde te aparece para colocarla, aunque parece que no la colocastes (Un error mio, el texto es blanco y el fondo tambien XD) pues dale a Guardar, luego, podras empezar a escribir, esta IA esta enfocada mas para portabilidad (y tambien seguridad), ya que con solo poner la KEY, podes usarla, y luego, cerrarla, y no se guarda NADA **OJO, LA APLICACION NO TIENE NINGUN TIPO DE TELEMETRIA MIA**
